# PDR (Product Requirements Document)

This directory stores Product Requirements Documents.

## Structure

Each PDR should be a markdown file (.md) containing:

- Title
- Problem Statement
- Proposed Solution
- Acceptance Criteria
- Timeline
- Dependencies

## Adding PDRs

1. Create a new .md file in this directory
2. Use the PDR template below
3. The file will be indexed into the database via migration

## Template

```markdown
# PDR Title

## Problem
Description of the problem being solved.

## Solution
Proposed solution approach.

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Timeline
Target completion date.

## Risks
Known risks and mitigations.
```
